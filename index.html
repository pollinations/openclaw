pollinations.ai × OpenClaw

Use Pollinations models in your OpenClaw agent. Connect once with the published Polli CLI, then choose from the current model catalog.

Feb 12, 2026 · Antler Berlin
Where it started: OpenClaw Builders Night
This integration was born at the OpenClaw Builders Night hackathon in Berlin. See the event that kicked it off.
1

Install OpenClaw and Polli

Install OpenClaw and Node.js, then install the published Polli CLI:

npm i -g @pollinations/cli
2

Connect your account

polli harness openclaw on

Run this in your terminal. Polli opens browser sign-in when needed, configures the Pollinations provider, fetches compatible models and installs the Polli skill. Credentials stay in your local CLI and OpenClaw configuration.

Generation uses your account's Pollen. See current balances and pricing.

3

Check and start chatting

polli harness openclaw status

If your gateway is already running, restart it with openclaw gateway restart to load the configuration. Then ask your agent a question.

Choose a model

Run polli models to see current models, or browse the live catalog. Choose a tool-calling text model and use its ID:

polli harness openclaw on --model MODEL_ID

In OpenClaw chat, switch with /model pollinations/MODEL_ID.

Image, video & audio

The CLI installs the published Polli skill for media generation. Ask your agent to generate an image, audio or video using Pollinations.

The original community integration by @isaacgounton is also available separately.

Update or disconnect

Update Polli with npm i -g @pollinations/cli, then rerun polli harness openclaw on to refresh the model catalog.

polli harness openclaw off restores the previous configuration, or removes only Pollinations entries if you have made other changes.
